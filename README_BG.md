# Скрейпър Oreshak.bg → Temu

Скрейпърът обхожда зададените 19 категории на `oreshak.bg`, отваря всяка продуктова страница и попълва оригиналния Temu шаблон, без да променя имената, реда на колоните, помощните листове, формулите и dropdown списъците.

## Какво събира

- код и име на продукта;
- пълно описание и до 6 bullet точки;
- цена в EUR и стара/препоръчителна цена, когато е налична;
- наличност;
- снимки само от продуктовата галерия, без изображения от описанието;
- тегло, размери, материали и други характеристики;
- реални продуктови варианти от select/radio полетата; полетата за гравиране не се третират като варианти;
- източник и автоматично избрана Temu категория.

## Задължителни полета

Програмата чете правилата директно от листа `GoodsLevelMode` в шаблона. След избиране на категория попълва всички нейни задължителни колони и прави собствена проверка преди запис. Ред с липсваща цена или основна снимка не се записва в Temu файла, а влиза във `validation_report.csv`/`failed_products.csv`, така че в готовия XLSX да няма непълен задължителен ред.

За полета, които не се публикуват в сайта, се използват разумни настройки и резервни стойности: опаковка 1 брой, доставка за 1 ден, произход България, ориентировъчни пакетни размери/тегло и наличност 10 броя. Те се виждат в `config.json` и могат да бъдат променени.

## Важно преди първото качване

В `config.json` са зададени:

```json
"manufacturer_name": "Еснафи ЕООД",
"eu_responsible_person": "Еснафи ЕООД"
```

Temu приема тези две полета само когато имената са предварително добавени в Seller Central. Ако в профила са записани по друг начин, сменете стойностите **буква по буква**. Dropdown списъкът в предоставения файл съдържа само инструкция, а не реалните имена от акаунта, затова те не могат да се извлекат автоматично от Excel.

## Стартиране на Windows

1. Инсталирайте Python 3.11 или по-нова версия.
2. Разархивирайте проекта.
3. Стартирайте `run_test.bat`.
4. Резултатите ще са в папка `output`.
5. След проверка стартирайте `run_full.bat`.

Ръчно изпълнение:

```bash
python -m pip install -r requirements.txt
python scraper.py --template template.xlsx --config config.json --limit 10
python scraper.py --template template.xlsx --config config.json --limit 0
```

Само една категория:

```bash
python scraper.py --limit 10 --category nojove-ot-balgaria
```

Проверка на шаблона без достъп до сайта:

```bash
python scraper.py --schema-only
```

## GitHub Actions

Качете цялата папка в GitHub. Отворете **Actions → Oreshak to Temu scraper → Run workflow**. Полето `limit` е `10` за тест и `0` за целия сайт. След приключване изтеглете артефакта `oreshak-temu-results`.

Сайтът понякога показва автоматична проверка на заявките. Скрейпърът използва `cloudscraper`, пауза между страниците, повторни опити и резервни селектори. Страници, които все пак не могат да бъдат прочетени, се записват във `failed_products.csv`, без да създават непълен ред в Temu файла.

## Резултатни файлове

- `TEMU_ORESHAK_UPLOAD.xlsx` — готовият Temu шаблон;
- `oreshak_raw_export.csv` — всички извлечени данни;
- `category_mapping_review.csv` — избраната Temu категория и основанието;
- `validation_report.csv` — проверка за всеки SKU;
- `failed_products.csv` — страници, които не са били прочетени;
- `scraper.log` — подробен лог;
- `run_summary.json` — брой обработени продукти и редове.

## Корекция на категория

Ако конкретен продукт трябва да е в друга Temu категория, добавете ред в `category_overrides.csv`:

```csv
product_code,product_url,temu_category_id
6372,,10072
,https://oreshak.bg/primeren-produkt,12179
```

При следващото изпълнение override-ът има приоритет пред автоматичните правила.
